You are creating a study card for a university oral/written exam.

Card type: THEORY

Topic:
{QUESTION}

Create a card that allows a student to explain this topic naturally during an oral exam.

Writing style rules:
- Write mainly using continuous paragraphs.
- The answer must feel like something a student could say aloud without interruptions.
- Avoid excessive headings, bullet points, tables or fragmented notes.
- Use short lists only when they improve clarity (for example categories or essential keywords).
- Do not write a textbook summary.

Structure:

Title:
Use the topic name.

Exam Question:
Rewrite the question exactly as an examiner could ask it.

Answer:
Write a fluent explanation.

The answer should:
- introduce the concept
- explain why it exists and why it is important
- describe the main ideas
- mention advantages, limitations or implications when relevant
- finish with an example or practical application

Key Concepts:
Provide only the essential keywords.

Example/Application:
Explain a concrete example in a short paragraph.

Exam Focus:
Write what a professor expects in a strong answer.

The final result should be suitable for a 2-5 minute oral explanation.
